# Image & Video Requirements — Dr. Nahal Website

Purpose: exact list of every photo/video needed, page by page, derived directly from the approved website copy (files 01–10 in this folder). User will source and provide all assets; this list is what to prepare.

**Tech note:** site will be built in Next.js with GSAP + ScrollTrigger scroll animation (zoom, pin, crossfade effects — see instituteofhealth.com reference). This means several images — especially the hero — will be **scaled up significantly on scroll**, so resolution requirements below are higher than a typical website.

**General rules for every photo:**
- Landscape AND portrait versions where noted — mobile needs portrait crops, desktop needs landscape/wide crops of the same shot when possible.
- No visible watermarks, stock-photo branding, or low-resolution phone screenshots.
- For any photo containing a patient's face, written consent is required before publishing.
