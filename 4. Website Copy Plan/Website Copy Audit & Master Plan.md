## 1. Bengali Writing Rule (non-negotiable, applies to every page)

Bengali copy is **NOT a literal translation** of the English copy. It is a **ভাবানুবাদ** (sense-for-sense rewrite) — written as if a Bengali-speaking patient is being spoken to directly, in natural conversational Bengali. No robotic phrasing, no word-for-word English sentence structure carried over. If it doesn't sound like something a person would actually say out loud, rewrite it.

English and Bengali versions of the same page can differ in structure/emphasis if that serves the reader better in that language — they don't have to mirror each other line by line.

## 7. Audit — What Else Is Commonly Missing (new findings, this pass)

Things a copywriter/dev will hit and get stuck on if not planned now:

| Gap | Why it matters | Recommendation |
|---|---|---|
| **FAQ page** | Reduces repetitive "does insurance cover this / how long is recovery / is it painful" questions, strong SEO too | Add as its own nav/footer page, 15–20 Q&A, sourced from real patient questions |
| **Privacy Policy** | Legally expected for any site collecting contact/appointment info | Standard page, short, in both languages |
| **Terms of Use / Medical Disclaimer** | Protects the practice — "this site is informational, not a substitute for in-person diagnosis" | Required, especially since disease pages give medical explanations |
| **404 page** | Video/image URLs will 404 as content grows — needs a branded, on-theme error page, not default | Simple, with search bar + link back to homepage |
| **Emergency/urgent-symptom notice** | Retinal detachment, sudden vision loss are TRUE emergencies — a small persistent banner or note ("call immediately if X") is a patient-safety issue, not just marketing | Add a short emergency-symptoms callout, likely on Contact + relevant condition pages |
| **Insurance/payment info** | Patients will ask "শনি বিল কত হবে" / "কার্ড নেওয়া হয় কিনা" — even a simple "contact for consultation fee" line avoids friction | Add to Chambers or Contact page |
| **hreflang / URL structure for EN vs BN** | Needed so Google indexes both language versions correctly, not as duplicate content | Technical note for dev, not copy — flag to Frontend/SEO agent |
| **Meta title/description per page** | Every one of the ~35+ pages needs its own, not just visible copy | Add as a column in the copywriter's tracking sheet |
| **Alt text policy for images (bilingual)** | Needed for both accessibility and image SEO | Standardize: descriptive alt text per language, not "image1.jpg" |
| **Breadcrumbs / related-page links** | Condition pages should cross-link to the matching Service page and vice versa (e.g. Cataract condition page ↔ Phacoemulsification service page) | Map this relationship before writing, so copy can naturally include the cross-link |
| **Downloadable pre-op/post-op instructions** | Common on surgical practice sites — builds trust, reduces phone calls | Optional add-on, flag for later phase, not blocking now |
| **WhatsApp CTA text** | You mentioned WhatsApp earlier as a contact channel — needs its own short CTA copy, distinct from "call now" | Add explicit WhatsApp CTA copy alongside phone CTA everywhere |
| **Testimonial sourcing/moderation process** | Reviews shown need a real sourcing plan (Google Business Profile widget vs manually curated) — copy can be drafted, but process should be decided | Flag to user: how will real reviews be collected before launch? |
| **Doctor's name — consistent spelling across EN/BN** | "Nahal Mostak Khan Arnob" vs "নাহাল মোস্তাক খান অর্ণব" — needs one locked spelling standard used everywhere (site, meta tags, schema) | Lock this now: pull exact spelling from GMC record + visiting card |
| **Schema.org markup (Physician/MedicalBusiness)** | Not copy, but copy structure (name, specialty, hours, address) needs to match what schema will require | Flag to Schema Architect agent — copy team should structure chamber info consistently to make this easy |
